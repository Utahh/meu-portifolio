# Cauan Lima — Portfólio

Site pessoal construído com React, TypeScript, Tailwind CSS v4 e Framer Motion.

## Stack

- [Vite](https://vitejs.dev/) + React + TypeScript
- [Tailwind CSS v4](https://tailwindcss.com/) (tokens de tema em `src/index.css`)
- [Framer Motion](https://www.framer.com/motion/) para animações e microinterações

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Conteúdo editável

- `src/data/experience.ts` — histórico profissional
- `src/data/skills.ts` — ferramentas e tecnologias
- `src/data/projects.ts` — empresa (ADDAI) e produtos
- `src/data/contact.ts` — e-mail e redes sociais (**atualizar com dados reais**)
- `src/components/ui/HeroVisual.tsx` — troque o miolo pelo `<img>` da foto de perfil quando disponível
- `public/projects/` — pasta sugerida para logos e prints dos projetos
